# xv6 OS Assignment

This repository contains implementations for the xv6 (x86) operating system assignment:

- **Question 1:** Virtual to Physical Address Translation (`va2pa`)
- **Question 2:** Physical Memory Statistics (`getmeminfo`)
- **Question 3:** Page Table Dumping (`vmprint`)
- **Question 4:** Lazy Memory Allocation (Demand Paging)

## Directory Structure
- `xv6-public/`: Modified kernel source files and user programs (`vatest.c`, `memtest.c`, `vmprinttest.c`, `lazytest.c`).
- `docs/`: Report and output screenshots.
